# My Academic Tutor — Public Website Build Scope

This package is intentionally the **complete public website before integrations**.

## Included
- Tutoring-first homepage
- Find-a-Tutor conversion flow in demo mode
- 10 subject pages
- 8 academic-level pages
- 1:1 tutoring page
- How matching works
- Interactive AI Tutor front-end demo
- Tutor standards / network page
- Tutor recruitment page + demo application
- Resource library + 6 full resource articles
- About, FAQs and Contact
- Academic Integrity
- Safeguarding draft
- Privacy draft
- Terms draft
- Mobile navigation
- SEO metadata, robots and sitemap
- Responsive design

## Intentionally NOT connected yet
- Email / Resend
- CRM / Supabase
- Authentication
- Payments / Stripe
- Booking calendar
- Live AI model
- Analytics
- Admin dashboard

## Build order from here
1. Review every public page and copy.
2. Refine visual design and mobile layout.
3. Add real tutor information only when verified.
4. Finalise pricing / commercial wording.
5. Finalise legal and safeguarding documentation.
6. Freeze the public website design.
7. Only then connect lead delivery, CRM, AI, analytics, booking and payments.
