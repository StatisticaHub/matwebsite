# My Academic Tutor — brand style direction

## Voice
Clear, calm, expert and human. Student-facing copy should explain the benefit first and the platform mechanics second.

Avoid internal/product language such as:
- lead qualification
- conversion layer
- matching model
- no fake directory
- funnel

Prefer:
- thoughtful matching
- tell us what you need
- suitable specialist tutor
- personalised support
- clear next step

## Typography
The build uses a dependency-free system font stack:
- Body/UI: Avenir Next → Segoe UI → Roboto → Helvetica/Arial
- Display headings: Iowan Old Style → Palatino → Georgia

This gives a modern interface with an academic/editorial display voice without adding external font services.

## Colour system
- Deep navy: #0A1F44 — headings and dark sections
- Primary blue: #155EEF — main calls to action
- Dark blue: #0B3B91 — CTA bands and strong links
- Ink: #10203A — body headings
- Muted text: #58667A — supporting copy
- Soft blue: #EDF4FF — panels and tags
- Cool off-white: #F6F9FD — section separation
- Border: #D7E1EE
- Success: #157F52
- Error: #B42318

The new palette gives clearer contrast and a stronger education/technology identity than the previous beige/gold system.
