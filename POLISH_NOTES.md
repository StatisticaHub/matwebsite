# Brand polish update

This version keeps the existing public-site structure but improves language, typography and contrast before any live integrations are added.

## Copy direction
- Benefit-led, student-facing language
- Less internal/product terminology
- Consistent CTA: “Find my tutor”
- Clearer explanation of human matching
- AI positioned as useful first help, not a sales bot
- Stronger academic-integrity language without sounding defensive

## Typography
- Body/UI: Avenir Next → Segoe UI → Roboto → Helvetica/Arial
- Display: Iowan Old Style → Palatino → Georgia
- No external font service or font files required

## Colour direction
- Navy #0A1F44
- Primary blue #155EEF
- Dark blue #0B3B91
- Ink #10203A
- Muted #58667A
- Soft blue #EDF4FF
- Cool background #F6F9FD
- Border #D7E1EE

## Accessibility/readability
- Stronger text/background contrast
- Blue primary CTAs instead of near-black
- Clear focus-visible states
- Cleaner form borders and focus rings
- Higher-contrast muted text
- Improved dark-section paragraph contrast
